# Certifying the unseen

Before trusting an apple, you turn it over. This is a small study of whether an AI grader, offered one more view of a 3D scene, asks for the view that shows the problem, and what it concludes when that view misses it.

**Read the report:** [sgolbabaei.github.io/certifying-the-unseen](https://sgolbabaei.github.io/certifying-the-unseen/). Every picture, prompt and reply from the runs is inside it.

The code, the rules written before the runs, and the run data are available on request.
